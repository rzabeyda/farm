# Базовая версия Free Stars (звёзды каждый день) — `base-v1`

Это готовая рабочая версия бота @freestars5bot (репозиторий теперь называется `farm`). Она сохранена как точка возврата.
Что бы мы ни меняли дальше (ферма, животные и т.д.), к этой версии всегда можно вернуться командой `git checkout base-v1`.

- Git-тег: **`base-v1`** (неподвижная метка, всегда указывает на эту версию)
- Сейчас `main` и `farm-dev` — это новая версия «Ферма» (бот @farm6bot, см. `README.md`). Эта старая версия живёт только под тегом `base-v1`.

## Что умеет эта версия

- Ежедневная кнопка «Я не бот!»: +1 звезда в день, стрик.
- Друзья: +1 звезда рефереру за каждый день, когда друг нажал кнопку. В профиле список друзей с зелёной галочкой (нажал сегодня) и красным крестиком (не нажал). Активный друг = нажимал сегодня или вчера.
- VIP за Telegram Stars (оплата инвойсом XTR): Gold 25 ⭐ (+1/день), Platinum 100 ⭐ (+5), Diamond 500 ⭐ (+25), Obsidian 1000 ⭐ (+50). Улучшение с доплатой разницы. Цены и бонусы: словарь `STATUSES` в `app.py`.
- Вывод звёзд (минимум 50), история выплат. Заявка приходит админу сообщением «@username запрос N Stars» с кнопкой «Выплачено».
- Админка `/admin` (только `ADMIN_ID`): статистика (всего, новых сегодня/вчера, заходы, VIP), заявки на вывод, топ рефоводов, ручные «Разослать напоминания» и «Бэкап сейчас».
- Уведомление админу «Новый юзер @username», уведомление о покупке VIP.
- Ежедневное напоминание в 12:00 МСК тем, кто не нажал кнопку (`/stop`, `/remind`).
- Ночной бэкап базы на сервере (14 копий, в чат не отправляется).
- Мини-приложение: золотой дизайн, анимации, онбординг, окно «Как играть», модалки.

## Как вернуться к этой версии

### 1. Посмотреть код версии (ничего не ломая)

```bash
git fetch --tags
git checkout base-v1
```

### 2. Вернуть `main` к базовой версии

Безопасный способ (история сохраняется): откатить коммиты после тега.

```bash
git checkout main
git revert --no-commit base-v1..HEAD
git commit -m "Return to base-v1"
git push origin main
```

Жёсткий способ (переписывает историю, только если уверен):

```bash
git checkout main
git reset --hard base-v1
git push --force-with-lease origin main
```

### 3. Выложить версию на сервер

Сервер: `root@84.200.33.70`, папка `/root/freestars`, сервис systemd `freestars`, порт 8020 за nginx, домен `freestars.zabeyda.lol`.

```bash
git checkout base-v1
scp app.py root@84.200.33.70:/root/freestars/app.py
scp static/index.html static/star.png static/main.jpg root@84.200.33.70:/root/freestars/static/
ssh root@84.200.33.70 "rm -f /root/freestars/game.py; systemctl restart freestars"
```

(`game.py` нужен только версии v2 — «очки и тапы»; базовой версии он не нужен.)

### 4. Данные

- База: `/root/freestars/freestars.db` (SQLite). Копии: `/root/freestars/backups/` и `freestars.db.pre-v2`.
- Старый код совместим с новой схемой базы (лишние колонки он игнорирует), так что откат версии не требует правки базы.
- Токен и настройки лежат только на сервере в `/root/freestars/.env` (в git их нет): `BOT_TOKEN`, `BOT_USERNAME`, `WEBAPP_URL`, `ADMIN_ID`, `MIN_WITHDRAW`, по желанию `REMIND_HOUR_UTC`, `BACKUP_HOUR_UTC`.

### 5. Включить / выключить бота

```bash
ssh root@84.200.33.70 "systemctl enable --now freestars"   # включить
ssh root@84.200.33.70 "systemctl disable --now freestars"  # выключить
```
